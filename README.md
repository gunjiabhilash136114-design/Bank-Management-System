📌 Project Description

The Bank Management System is a web-based application developed using Advanced Java technologies.

The project is designed to manage customer information, bank accounts, deposits, withdrawals, and transaction records.

🛠 Technologies Used

- Java 17
- Spring MVC
- JSP, JSTL and EL
- Hibernate ORM
- MySQL
- HTML, CSS and JavaScript
- Apache Maven
- Apache Tomcat 10.1

✨ Features

1. User Login and Logout
2. Dashboard
3. Customer Management
4. Add, View, Update and Delete Customers
5. Bank Account Management
6. Deposit Money
7. Withdraw Money
8. Transaction History
9. Session Management
10. Form Validation

🗄 Database

Database Name: "bank_management"

Main Tables:

- customers
- accounts
- transactions

💻 Installation Instructions

1. Install JDK 17.
2. Install Apache Maven.
3. Install Apache Tomcat 10.1.
4. Install MySQL.
5. Create the "bank_management" database.
6. Import the database SQL script.
7. Configure the database connection.
8. Build the project using "mvn clean package".
9. Deploy the WAR file to Apache Tomcat.
10. Open the application in a web browser.
